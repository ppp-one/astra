astra.utils.optics#

Pure optics math shared across device-based and FITS-header-based code paths.

paired_devices.py derives plate scale from live Alpaca Camera/Telescope device properties, while pointer.py derives it from FITS header metadata (XPIXSZ/FOCALLEN). Both then need the same downstream math (plate scale, field of view, FWHM in pixels), so that math lives here as plain functions over floats/arrays with no device or FITS dependencies.
